# estateflow-real-estate

**EstateFlow Realty** — a premium real estate website demo for a fictional boutique brokerage in Austin, TX. Built as Day 1 of a 30-day website project series.

## What it demonstrates

A complete property-listing experience of the kind real estate agents, property managers and property developers need on their websites:

- **Property search that actually works** — live text search plus filters for property type, min/max price and minimum beds, with an instant result count and an empty state when nothing matches
- **Sorting** — price low to high, high to low, newest listed, and largest by square footage
- **12 property listings** with real photography, prices, beds/baths/sq-ft, addresses and Austin neighbourhoods (Zilker, West Lake Hills, Hyde Park, Downtown, Mueller…)
- **Property detail view** — large photo, full spec grid (beds, baths, sq ft, type, year built, garage, lot, price per sq ft), description and a listing-agent contact card
- **Inquiry / book-a-tour form** — per-field validation with inline errors and a personalised success confirmation; "Request a Tour" from any property pre-fills the form for that listing
- **Premium agency sections** — featured listings strip, stats bar (homes sold, years, rating, sales volume), client testimonials, office hours and full contact footer

## Tech

- Plain **HTML, CSS and JavaScript** in a single `index.html` — no build step, no framework, no dependencies
- Listings are rendered from a JavaScript data array, so swapping in a real client's inventory (or wiring it to a listings API/CRM) is straightforward
- Fully responsive layout, sticky header, smooth scrolling, hover states and a modal detail view

## Run it

Open `index.html` in any browser — that's it. (Photos live in the `images/` folder next to it.)

## For clients

This demo is available to adapt for real estate agents, property managers and property developers — your branding, your listings, your neighbourhoods, plus extras like map search, mortgage calculators, saved favourites and lead capture to your CRM.
